# OM Companion Actions

Flow:

```
understand → plan structured action → policy → approve? → execute → verify → reply
```

Examples:

- `application.open` (VS Code / Safari / Finder)
- `filesystem.list|read|write|move|delete`
- `browser.open|navigate`
- `process.list|start|stop`
- `system.notification`

Destructive actions never auto-run.
