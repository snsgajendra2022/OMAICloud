# Assets that cannot be manufactured by source code alone

OM AI now contains executable software for corpus governance, pretraining, SFT, reward modeling, DPO, benchmarks, feedback replay, multimodal encoding and integrations. The following are inputs/results of real-world training rather than files that can honestly be fabricated in a source ZIP.

| Item | Code in repository | External input required | Produced after running work |
|---|---|---|---|
| Billions/trillions of licensed tokens | Yes: manifest, cleaning, dedupe, audit, sharding | A legally usable corpus | Tokenized training shards |
| Months/large-scale GPU training | Yes: single GPU, DDP, FSDP, DeepSpeed paths | GPU cluster, power, storage, scheduler, time | Pretrained checkpoints |
| Trained 7B/13B/70B weights | Yes: architectures + trainers | Corpus + compute | Owned OM weight files |
| Instruction tuning | Yes: masked SFT trainer | High-quality instruction/response data | SFT checkpoint |
| RLHF/preference training | Yes: reward model + DPO | Human/curated preference pairs | Reward/DPO checkpoints |
| Massive benchmark runs | Yes: benchmark runner/reporting | Evaluation datasets + compute | Reports and regression history |
| Vision intelligence | Yes: trainable ViT + multimodal projector | Paired image/text or task labels + compute | Vision/VLM weights |
| Speech recognition foundation | Yes: STFT features + Transformer speech encoder + CTC head | Large speech/transcript corpus + compute | ASR weights |
| Natural TTS voice | Interface only in this release | A dedicated TTS architecture/data/training project or legally provisioned local weights | TTS weights |
| World knowledge comparable to a frontier model | Learning/training system exists | Very large broad/high-quality corpus + substantial compute/post-training | Encoded in trained weights |
| Every CRM/medical/ecommerce/desktop product | Plugin SDK + constrained generic REST connector | Each product's schema, credentials, permissions, business rules and testing | Installed integration plugins |
| WhatsApp production transport | Adapter contract + development adapter | A supported transport implementation/session/credentials and compliance with platform terms | Working channel transport |
| Guaranteed AGI/JARVIS | No scientifically valid guarantee exists | Not a well-defined deliverable | No honest guarantee can be made |

The included `artifacts/demo/om-tiny-dpo.pt` is a real checkpoint generated by running pretraining -> SFT -> DPO on the tiny development corpus. It demonstrates the pipeline; it is intentionally not represented as a capable production brain.
